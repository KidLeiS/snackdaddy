# Snackdaddy logo assets

## Palette

- Snackdaddy Yellow: `#FFD400`
- Snackdaddy Black: `#10110E`

## Usage

- Use `snackdaddy-wordmark-black` on yellow or pale backgrounds.
- Use `snackdaddy-wordmark-yellow` on black backgrounds.
- Use the `snackdaddy-mark` files for favicons, avatars, and square placements.
- Use `br-oats-wordmark-black` on yellow packaging or campaign backgrounds.
- Use `br-oats-lockup-reversed` when the product descriptor must travel with the logo.
- Keep clear space around each logo equal to at least the height of the full stop in the Snackdaddy wordmark.
- Do not stretch, skew, outline, recolour, or add effects to the marks.

SVG files are the master assets. PNG files are convenience exports for tools that do not accept SVG.
